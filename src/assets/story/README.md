# 图片题：剧情画面素材

6 张 2×2 分镜图，每张包含一道题的四个情境。人物采用同一套服装与外观，帮助读者辨认“我”和“TA”；题目不以人物性别、外貌或表情判断好感。

| 文件 | 题目 | A → D 的叙事区别 |
| --- | --- | --- |
| messages.webp | 谁主动开场 | 我开场／有事联系／分享小事／没事也来聊天 |
| coffee.webp | 是否记得细节 | 忘记重要安排／只记得大事／想起小喜好／按喜好行动 |
| crowd.webp | 人群中的关注 | 少主动找我／平等照顾大家／主动接我的话／散场后继续相处 |
| news.webp | 回应好消息 | 转回自己的话题／简短祝贺／积极追问／之后也记得庆祝 |
| calendar.webp | 具体邀约 | 多次不成行／只说改天／确定日期／主动提出替代日期 |
| activity.webp | 共同活动 | 仍是单人出行／由我单方面安排／一起协商／轮流提议并参与 |

素材由图像生成工具根据这些分镜创作，WebP 用于减小网页体积。原始 PNG 保留在工作区的 `/workspace/generated_images`。更新时应以选项描述为依据，不额外画出牵手、告白等题目未记录的事实。

`src/choice-scenes.js` 保存每张图片的剧情说明、短对白以及分镜边界。`src/choice-illustrations.js` 在浏览器中裁出相应画面并叠加可读的中文，不依赖模型生成的字形。若新素材分隔位置改变，需核对并调整边界。

画面只能演绎一个片段；“多次”“后续”等持续性依据来自用户选择的完整文字，不能单靠一张图推断。所有图片内联，下载版没有外部图片请求。
